## Summary

This project is a web application focused on holiday planning, allowing users to book hotels and cars easily.

## Installation

### Frontend
1. Node.js (last version)
2. Angular: type in the command prompt npm install -g @angular/cli. And confirm with ng version
3. Go to /frontend and type npm install
4. Deploy with ng serve -o
   
## Backend
1. Composer (last version)
2. Create a .env and type the necessary parameters to connect your database
3. Go to /backend and type composer install
4. Create database proyectoalojamientos and type in /backend: php artisan migrate
5. Deploy with php artisan serve
